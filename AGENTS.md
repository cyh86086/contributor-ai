# Repository instructions

Before starting any development task in this repository:

1. Read `docs/PROJECT_STATE.md`.
2. Read `docs/DECISIONS.md`.
3. Treat those committed documents, together with the repository contents, as
   authoritative.

Update `docs/PROJECT_STATE.md` in the same change whenever module status,
project phase, a blocker, runtime architecture, the next milestone, or release
status changes.

Never commit API keys, tokens, credentials, or secrets. Do not recreate or mark
historical modules complete without satisfying the migration and verification
rules in `docs/PROJECT_STATE.md`.
